# OhHelp v2 Documentation

This directory contains documentation for the independent ohhelp2 v2 line.

- [`usage/`](usage/README.md) is the user-facing guide for C and Fortran users.
- [`design/`](design/) contains implementation notes and migration contracts.

The supported v2 surface currently focuses on Level 1-3. Level 4p/4s source
files remain under compile coverage while full v2 support continues separately.
